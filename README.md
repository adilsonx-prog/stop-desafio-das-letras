# Stop! Desafio das Letras

Crie um aplicativo web multiplayer chamado STOP – DESAFIO DAS LETRAS.

Quero desenvolver um jogo online para celulares e computadores, com interface moderna, colorida e responsiva.

Nesta primeira etapa, desenvolva:

Tela inicial com botão Criar Partida.

Opção Entrar em Partida por código.

Cadastro de nome do jogador, sem exigir conta.

Sala de espera com lista de participantes.

Botão para compartilhar convite.

Tela principal do jogo com as 9 categorias.

Letra sorteada em destaque.

Campos para digitar as respostas.

Botão STOP grande e destacado.

Placar dos jogadores.

Prepare a estrutura para multiplayer em tempo real usando Supabase.

Não faça apenas uma imagem ou protótipo estático. Quero uma aplicação funcional, preparada para conectar vários jogadores simultaneamente.

Priorize a experiência em celulares Android.
